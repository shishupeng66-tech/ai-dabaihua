# AI大白话知识库目录结构与加载策略 v1

## 一、目标

本阶段确定 AI大白话知识库在项目中的存储方式、加载方式和未来扩展方式。

目标：

-   支持数千级知识条目扩展
-   保持搜索性能
-   方便人工维护

-   支持版本管理

# 三、文件职责

## index.json

知识库索引。

作用：

快速定位词条属于哪个分类。

示例：

``` json
{
  "Token": {
    "file": "llm.json",
    "priority": "P0"
  },
  "FFmpeg": {
    "file": "media-ai.json",
    "priority": "P0"
  }
}
```

------------------------------------------------------------------------

## version.json

知识库版本管理。

示例：

``` json
{
  "version": "1.0.0",
  "updatedAt": "2026-01-01",
  "totalTerms": 500
}
```

# 五、单文件规模控制

不建议：

一个 knowledge.json 放几千条。

原因：

-   加载慢
-   更新困难
-   审核困难

建议：

单文件：

500条以内。

超过：

拆分。

------------------------------------------------------------------------

# 六、搜索加载策略

## 第一层：索引匹配

用户输入：

Token

流程：

    index.json
     ↓
    定位 llm.json
     ↓
    读取词条
     ↓
    返回知识库答案

------------------------------------------------------------------------

## 第二层：分类搜索

如果没有精确命中：

搜索：

-   aliases
-   relatedTerms
-   commonQuestion

------------------------------------------------------------------------

## 第三层：AI解释

知识库没有：

进入：

    Intent Router
     ↓
    Skill
     ↓
    CloudBase hy3

------------------------------------------------------------------------
