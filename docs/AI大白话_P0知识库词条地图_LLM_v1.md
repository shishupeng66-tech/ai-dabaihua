# AI大白话 P0知识库词条地图 v1

## 分类：大模型与LLM（llm.json）

## 一、目标

本词库负责覆盖用户理解大模型、生成式AI、ChatGPT类产品时最常遇到的核心概念。

目标：

-   普通用户能理解AI产品中的常见英文词
-   开发者能快速了解技术概念
-   为后续完整解释内容生产提供词条清单

本阶段只建立词条地图，不生成详细解释。
