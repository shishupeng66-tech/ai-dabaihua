# AI大白话知识库分类体系 v1

## 一、项目定位

AI大白话不是传统 AI 百科，而是 AI 时代的知识解释入口。

目标：

用户遇到陌生 AI 相关词汇、软件、技术概念时，可以快速理解： - 它是什么 -
它有什么用 - 它和哪些概念有关

# 三、建设原则

1.  不做传统百科，重点解释和应用。
2.  所有词条必须归属分类。
3.  每个词条建立相关概念关系。
4.  知识库持续增长。
